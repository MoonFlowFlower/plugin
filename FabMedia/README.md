# Runtime Inspector Fab Media Staging

This file is a Fab media staging note, not the RuntimeInspector agent development authority.

For implementation rules and development workflow authority, use `docs/AGENT_DEVELOPMENT.md`.

Place the final Fab listing media in this folder before submission.

The automated capture script writes a deterministic staging set to:

- `Saved/RuntimeInspector/FabMediaCapture/`

Review those files first, then copy the approved final assets into this folder.

## Capture Rules

- Use only shipped UE 5.5 functionality
- The deterministic capture path first resolves `panelHostWindowDebug`, then uses the project UE MCP bridge `capture_window_screenshot` action against that exact host window.
- `capture_window_screenshot` is the whole-window authority for RuntimeInspector visuals; do not route Preview shots through `capture_screenshot`.
- Match the wording in `RuntimeInspector.uplugin`, `README.md`, and `FAB_LISTING.md`
- Do not show debug leftovers, broken assets, compile logs, or temporary internal notes
- Prefer one clean scene and one consistent UI scale across screenshots

## Suggested Flow

1. Use `Scripts\PackageFabRelease.cmd` to refresh the clean package.
2. Use `Scripts\OpenFabScreenshotState.cmd` to normalize the screenshot presentation state in the main project.
3. Use `Scripts\CaptureFabMedia.cmd` to generate the deterministic screenshot staging set in `Saved\RuntimeInspector\FabMediaCapture\` through the UE MCP host-window screenshot path.
4. Review the staged PNG files and then copy the approved media into this folder.

Do not use the blank validation host for final Fab screenshots. It exists only for install/load smoke validation.
