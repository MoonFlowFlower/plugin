## 2. 当前未闭合主问题

### 2.1 Settings 持久化仍未闭合

用户的真实症状：

- 在 `Settings` 里把 `Outline Weight` 改到例如 `5`
- 点击保存
- 停止 PIE，再重新进入 PIE
- 数值又回到 `0`

已知事实：

- [DefaultGame.ini](/mnt/d/Project/Game/UE/PluginMaker/Config/DefaultGame.ini) 当前已经存在：
  - `[/Script/RuntimeInspector.RuntimeInspectorSettings]`
  - `OutlinePPWeight=0.500000`
- 因此“完全没写盘”不是完整解释
- 更可能的根因是：
  1. `Save` 时 UI 当前值未稳定同步到保存 authority
  2. `PIE` 新世界启动时没有按同一 authority 回读 config
  3. 或者有运行态初始化链在世界起来后再次把 outline runtime state 覆盖掉

### 2.2 Bridge 当前不可信

这轮多次出现：

- [bridge_state.json](/mnt/d/Project/Game/UE/PluginMaker/Saved/UE_MCP_Bridge/bridge_state.json) 显示 `active=true, port=9877`
- 但实际 `9877~9881` 全部 `ECONNREFUSED`

这意味着：

- 不能把 bridge state 文件当作“bridge 真在线”的 authority
- 当前很多运行态 self-test / screenshot 证据在这轮拿不到

- `OutlineWeightSpinBox`
- outline checkbox
- debounce checkbox / spinbox
- 其他 settings checkbox

把当前 UI 状态同步回 `DraftSettings`，不再依赖之前某次 `OnValueChanged` 已经成功触发。

#### B. 显式 config authority

在 [InspectorWorldSubsystem.cpp](/mnt/d/Project/Game/UE/PluginMaker/Plugins/RuntimeInspector/Source/RuntimeInspector/Private/InspectorWorldSubsystem.cpp) 里新增了显式 helper：

- `RI_ApplyEditableSettingsToRuntimeInspectorSettings(...)`
- `RI_ReadEditableSettingsFromConfigFile(...)`
- `RI_WriteEditableSettingsToConfigFile(...)`
- `RI_LoadSettingsFromConfigAuthority(...)`

意图是：

- 保存时同时写 `DefaultConfigFilename` 和 `GGameIni`
- 初始化 / reload 时按同一 authority 回读
- 然后把回读值显式覆盖回 `URuntimeInspectorSettings`

当前口径：

- **编译通过**

### 6.1 先不要继续改 UI

当前主阻塞不是 UI 观感，而是 `Settings` 持久化 authority 没有闭环。

### 6.2 最短验证闭环

按这个顺序：

1. 修复 / 恢复 bridge，确认端口真实可连
2. 冷启动 UE
3. 跑 `settings_save_persistence`
4. 再做一次人工链：
   - 进 PIE
   - `Outline Weight = 5.00`
   - Save
   - Stop PIE
   - Start PIE
   - 观察值是否仍为 `5.00`

### 6.3 如果依然失败，优先查这几个点

1. `URuntimeInspectorSettings` 在 `PIE` 新世界起来后是否被其它路径再次覆盖
2. `GetDefaultConfigFilename()`、`GGameIni`、`Saved/Config` 实际运行时哪个才是最终 authority
3. `RefreshOutlineRuntimeSettings()` / `EnableOutlinePP()` 是否只更新了运行态效果，而设置页读取的仍是另一份默认对象状态
4. 是否存在 PIE 生命周期中的额外初始化钩子在 subsystem 之外重置 outline 相关值
